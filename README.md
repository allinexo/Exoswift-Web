# ExoSwift project page

Static, dependency-free project website assembled from the manuscript,
presentation figures, and demonstration videos.

## Preview locally

Run a local static server in this directory, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Asset notes

- Animated previews are rendered at 12 fps.
- The included manuscript has no author metadata or visible author/affiliation block.
- The page includes `noindex, nofollow`. Remove that meta tag when the project is
  ready for public indexing.
